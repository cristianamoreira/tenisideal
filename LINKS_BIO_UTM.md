# Links pra colar na bio (com etiqueta UTM)

Esses links são iguais ao normal, mas com uma "etiqueta" no final que faz o
Google Analytics separar de onde veio cada visita. Copie e cole na bio.

## Instagram (bio)
```
https://tenisideal.com.br/?utm_source=instagram&utm_medium=bio
```

## TikTok (bio)
```
https://tenisideal.com.br/?utm_source=tiktok&utm_medium=bio
```

---

## Se quiser rastrear um post/vídeo específico
Troque o `utm_campaign` pelo nome do post (sem espaços, sem acento):

TikTok — vídeo sobre pisada pronada:
```
https://tenisideal.com.br/?utm_source=tiktok&utm_medium=bio&utm_campaign=video-pisada-pronada
```

Instagram — carrossel top Nike:
```
https://tenisideal.com.br/?utm_source=instagram&utm_medium=bio&utm_campaign=carrossel-top-nike
```

## Onde ver o resultado
Google Analytics → Relatórios → Aquisição → Aquisição de tráfego.
A coluna "Origem/mídia" vai mostrar `instagram / bio` e `tiktok / bio` separados.

Regras rápidas do UTM: tudo minúsculo, sem espaço (use hífen), sem acento.
